# Legacy deployment snapshots

이 디렉터리는 2026년 7월 팀 프로젝트의 분산 실행 토폴로지를 검증하기 위해 남긴 배포 문서입니다. 현재 권장 설치 경로는 저장소 루트의 `charts/opsia` Helm chart입니다.

공개 저장소 정리 과정에서 ECR account ID는 `000000000000`으로 치환했습니다. 따라서 이 문서의 image 주소를 그대로 배포에 사용하면 안 됩니다. Deployment 수와 replica 선언은 [아키텍처 비용 회고](../docs/portfolio/architecture-cost-postmortem.md)의 Git 증거로만 사용합니다.
